## 2. Milyen adatokat kezelünk?

A Hoppá Park mobilalkalmazás használata során az alábbi adatokat kezelhetjük:

- Név (Google vagy Apple fiókból)
- E-mail cím (Google vagy Apple fiókból)
- Profilkép (Google bejelentkezés esetén)
- Apple felhasználói azonosító (Apple bejelentkezés esetén)
- Push értesítési azonosító (APNs vagy FCM token)
- Profiladatok (bemutatkozás, zenei stílusok, érdeklődési körök, képek)
- Match rendszerhez kapcsolódó adatok
- Chat üzenetek
- Közösségi hirdetések
- Nyereményjáték jelentkezések
- Belépési időbélyegek

## 6. Adattárolás és adatfeldolgozók

Az alkalmazás működéséhez az alábbi szolgáltatókat használhatjuk:

- Google LLC (Google Sign-In)
- Apple Inc. (Sign In with Apple)
- Apple Push Notification Service (APNs)
- Google Firebase Cloud Messaging (FCM)
- MongoDB Atlas

Az adatok kizárólag a szolgáltatás működtetéséhez szükséges mértékben kerülnek feldolgozásra.
